# Free Fire Events - Cập Nhật Sự Kiện 24/24

Ứng dụng web quản lý và cập nhật sự kiện Free Fire hoạt động 24/24.

## Tính năng chính

- ✅ Hiển thị sự kiện đang diễn ra và sắp diễn ra
- ✅ Banner tự động xuất hiện trước 10 ngày
- ✅ Tự động xóa banner sau 4-5 ngày kết thúc sự kiện
- ✅ Nút sao chép link banner
- ✅ Tự nhận dạng hình ảnh, hiển thị "ĐANG CẬP NHẬT" nếu không có
- ✅ Countdown thời gian thực
- ✅ Tìm kiếm và lọc sự kiện
- ✅ Responsive design

## Cài đặt

### Deploy lên Vercel

1. Đăng nhập vào Vercel
2. Import repository từ GitHub
3. Vercel sẽ tự động nhận diện cấu hình
4. Click Deploy
